# Оркестрация Агентов Сопровождения Проекта

В проекте MyGemini Zero v2 внедрена система распределённых ролей (агентов) для автоматического и непрерывного ведения проектной документации.

## Состав команды агентов:

```
┌─────────────────────────────────────────────────────────────┐
│                 ОРКЕСТРАТОР РАЗРАБОТКИ                      │
└──────┬───────────────────────┼───────────────────────┬──────┘
       │                       │                       │
       ▼                       ▼                       ▼
┌──────────────┐       ┌──────────────┐        ┌──────────────┐
│  ЛЕТОПИСЕЦ   │       │ БАГ-ТРЕКЕР   │        │ АРХИТЕКТОР   │
│ (Chronicler) │       │ (QA & Bugs)  │        │   (Features) │
└──────┬───────┘       └──────┬───────┘        └──────┬───────┘
       │                      │                       │
       ▼                      ▼                       ▼
  • DEVLOG.md            • BUGS.md               • FEATURE_IDEAS.md
  • CHECKLIST.md         • BUG_TRACKER.md
  • ROADMAP.md
```

### 1. Агент-Летописец ([chronicler_agent.md](chronicler_agent.md))
* **Триггер вызова:** После каждой операции создания, модификации кода или завершения задачи.
* **Результат:** Обновлённый `DEVLOG.md` от первого лица и проставленные чекбоксы в `CHECKLIST.md`.

### 2. Агент Баг-Трекер ([qa_bug_agent.md](qa_bug_agent.md))
* **Триггер вызова:** При появлении ошибок в логах, падении тестов или регрессиях.
* **Результат:** Запись в `BUGS.md`, анализ причин (RCA) и фиксация решения в `BUG_TRACKER.md`.

### 3. Агент Архитектор Фич ([feature_architect_agent.md](feature_architect_agent.md))
* **Триггер вызова:** При поступлении предложений по новому функционалу.
* **Результат:** Проработанная карточка в `FEATURE_IDEAS.md` с оценкой приватности и трудоемкости.

---

## Регламент взаимодействия:
Все агенты работают в едином контексте. При любой активной сессии разработки главный агент Antigravity берет на себя исполнение этих ролей, гарантируя, что **ни одно действие, баг или идея не останутся незафиксированными**.
