# Реестр обнаруженных багов: MyGemini Zero v2 (Bugs Log)

> Файл фиксации всех найденных дефектов, регрессий и неожиданного поведения системы на этапах разработки и тестирования.

## Структура карточки бага:
* **ID:** Уникальный идентификатор (`BUG-001`, `BUG-002`...)
* **Дата:** Дата и время регистрации
* **Критичность:** `Blocker` (блокер) / `Critical` (критический) / `Major` (высокий) / `Minor` (низкий)
* **Статус:** `New` (новый) / `In Progress` (в работе) / `Resolved` (исправлен) / `Cannot Reproduce` (не воспроизводится)
* **Компонент:** Модуль системы (`Auth`, `Gemini`, `RAG`, `Payments`, `Database`, `UI`)
* **Описание проблемы:** В чем заключается дефект
* **Шаги для воспроизведения:** 1, 2, 3...
* **Ожидаемое поведение vs Фактическое:**
* **Ссылка на решение:** Ссылка на запись в `BUG_TRACKER.md`
