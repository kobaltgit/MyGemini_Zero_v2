# Дорожная карта проекта: MyGemini Zero v2 (Roadmap)

## 📌 Статус проекта: [В РАЗРАБОТКЕ / ИНИЦИАЛИЗАЦИЯ]
* **Начало:** Сентябрь 2026 г.
* **Архитектурный фокус:** Высокая производительность (`aiogram 3`, async SQLAlchemy), потоковый вывод ответов (Streaming), безопасный Zero-Knowledge контур, 100% обратная совместимость данных и платежей.

---

[Этап 7: Навигация & FSM] ──> [Этап 8: Безопасность & ZK] ─> [Этап 9: Двуязычность (i18n)]

### Этап 1: Архитектурный фундамент и Окружение [x]
* [x] Проектирование модульной структуры каталогов проекта.
* [x] Создание файла зависимостей `requirements.txt` / `pyproject.toml` (`aiogram>=3.17.0`, `google-genai>=1.0.0`, `sqlalchemy[asyncio]>=2.0.0`, `aiosqlite>=0.20.0`, `cryptography>=43.0.0`, `bcrypt>=4.2.0`).
* [x] Настройка конфигуратора `settings.py` на `pydantic-settings` с валидацией `.env`.
* [x] Создание файла `docker-compose.yml` и `Dockerfile` для лёгкого self-hosted запуска.
* [x] Настройка структурированного логирования.

### Этап 2: База данных и Zero-Knowledge криптография [x]
* [x] Описание декларативных моделей SQLAlchemy 2.0 (`User`, `Dialog`, `Conversation`, `UserProfile`, `AppSettings`).
* [x] Реализация асинхронной сессии БД (`get_async_session`) без глобальных блокировок.
* [x] Реализация криптографического модуля (`crypto.py`):
  * Точная деривация ключей через PBKDF2 (480 000 итераций) для 100% совместимости с v1.
  * Работа с солью (`encryption_salt`) и Fernet.
  * Верификация bcrypt-хешей мастер-пароля и пароля паники.
* [x] Реализация репозиториев для пользователей, диалогов и истории сообщений.

### Этап 3: Сервис Google Gemini и Потоковая генерация (Streaming) [x]
* [x] Интеграция официального `google-genai` SDK.
* [x] Реализация генерации ответа в потоковом режиме (`generate_content_stream`).
* [x] Реализация умного троттлера редактирования сообщений в Telegram (интервал 1.0–1.2 сек) с учётом лимитов Telegram Bot API (Flood control).
* [x] Поддержка мультимодальности (обработка фото и голосовых сообщений).
* [x] Подключение инструментов: `google_search` и `code_execution` (Python sandbox).

### Этап 4: Роутинг, FSM и Платёжный шлюз [x]

* [x] Перенос и регистрация платёжного шлюза:

* [x] Роутеры команд (`/start`, `/logout`, `/reset`, `/settings`, `/dialogs`).
* [x] Интерактивные меню на `InlineKeyboardMarkup` с `CallbackData`.

### Этап 5: Векторная память (RAG) и Мультидокументы [x]

### Этап 6: Миграция данных, Регрессионное тестирование и Релиз [x]
* [x] Скрипт валидации существующей базы данных `bot_database.db` и векторного каталога `vector_store/`.

### Этап 7: Устранение дефектов навигации, сброс FSM и безопасный edit_text [x]
* [x] Разработка универсального вспомогательного метода безопасного редактирования сообщений `safe_edit_message_text`:
  * Подавление ошибки `TelegramBadRequest: message is not modified`.
  * Корректная обработка `InaccessibleMessage` и сообщений без текста (подписи к медиа).
* [x] Ликвидация ловушек FSM (FSM State Traps):
  * Вызов `await state.clear()` при клике на «❌ Закрыть» (`close_menu`).
  * Вызов `await state.clear()` при возврате «⬅️ В главное меню» (`back_to_main`) и «⬅️ Назад к диалогам» (`dialog_list`).
* [x] Возврат кнопок «⬅️ Отмена / Назад» и «❌ Закрыть» на все экраны ожидания ввода:
  * Ввод мастер-пароля в чате (`vault_unlock_chat_prompt`).
  * Первичная установка мастер-пароля (`vault_setup_chat_prompt`).
  * Ввод API-ключа (`api_key_chat_prompt`).
  * Анкета профиля (`ProfileStates`).
* [x] Регистрация недостающих обработчиков для «мёртвых» кнопок:
  * Меню настройки паник-пароля (`settings_panic`).
  * Меню архивации памяти диалога (`memory_archive_start`).
* [x] Разрешение конфликта роутеров `/start`:
  * Перенос приоритета онбординга и проверки сессии в `start_router`.
  * Устранение дублирования логики между `commands.py` и `start.py`.
* [x] Синхронизация логики навигации Reply-клавиатуры и Inline-меню.

### Этап 8: Безопасность Zero-Knowledge и Критические сервисы [x]
* [x] Двухэтапная установка мастер-пароля с повторным подтверждением (`zk_confirm_prompt`) и проверкой совпадения (`zk_password_mismatch`).
* [x] Двухэтапная установка паник-пароля с подтверждением и защитой от совпадения с основным паролем.
* [x] Отправка персональных уведомлений администратору в Telegram:
  * При оплате и продлении подписки (`notify_admin_of_subscription_payment`).
  * При регистрации нового пользователя (`notify_admin_of_new_user`).
* [x] Восстановление расширенного парсера ошибок Gemini API (`services/error_parser.py`):
  * Обработка квот 429, перегрузки 503, recitation, safety-блокировок.
* [x] Буферизация и дебаунс входящих медиа-сообщений (`_process_buffered_messages_task`).

* [x] Создание централизованного модуля локализации `core/localization.py`:

* [x] Добавление пункта смены языка в меню настроек:

* [x] Расширение анкеты профиля до 8 структурированных вопросов с инлайн-кнопками быстрого выбора и точечным редактированием полей.
* [x] Механизм обратной связи и отчёта об ошибках (`/feedback`, `/report_error`).
