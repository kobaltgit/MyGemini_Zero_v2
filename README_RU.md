## Зачем нужен MyGemini Zero? (Концепция)

Стандартные нейросетевые интерфейсы страдают от **цифровой амнезии**: они забывают контекст ваших проектов сразу после завершения разговора. Кроме того, сторонние боты-посредники требуют безраздельного доверия к их серверам и базам данных, где в открытом виде хранятся ваши переписки и персональные API-ключи.

**MyGemini Zero** решает обе проблемы на фундаментальном уровне:

### 1. Долговременная память: Ваш личный «Второй мозг»
Бот интегрирован с изолированной векторной базой данных (ChromaDB), превращая диалоги, заметки и загруженные документы в долговременную память. Перед отправкой запроса к Google Gemini бот автоматически находит релевантный контекст из прошлых обсуждений. Вы можете спросить: *«Какие риски мы выявили в маркетинговом плане две недели назад?»*, и ассистент моментально вспомнит детали.

### 2. Приватность Zero-Knowledge (Нулевое разглашение)
Ваши диалоги, профиль и Google API-ключ шифруются стойким шифром Fernet прямо в оперативной памяти на базе **мастер-пароля**, который знаете **только вы**:
* **Нулевое доверие к посредникам:** Создатели сервиса и администраторы серверов **криптографически не могут** прочесть ваши данные — у них просто нет ключа от вашего цифрового сейфа.
* **Ключи только в RAM:** Ключ деривируется на лету через PBKDF2 (480 000 итераций) и полностью стирается из памяти по окончании сессии.
* **Пароль паники (Правдоподобное отрицание):** В экстренной ситуации ввод аварийного пароля тихо и необратимо стирает всю базу сообщений, векторную память и привязанные ключи.

### 3. Модель BYOK (Bring Your Own Key) и Open Source
* Бот работает на вашем личном ключе Google Gemini API (бесплатный тариф Google AI Studio или личный аккаунт). Мы не делаем наценку на токены и не продаем слова модели.
* Исходный код открыт под лицензией **AGPLv3**. Вы можете пользоваться готовой круглосуточной инфраструктурой сервиса [@mgemz_bot](https://t.me/mgemz_bot) или бесплатно поднять своего бота на личном сервере.

Версия v2 была полностью переписана с нуля для устранения архитектурных ограничений v1, при этом сохранив **100% совместимость** с существующей базой пользователей и векторной памятью.

| Характеристика | Версия 1 (MyGemini_Zero) | Версия 2 (MyGemini_Zero_v2) |
| :--- | :--- | :--- |
| **Telegram-движок** | Синхронный `telebot` (pyTelegramBotAPI) с ручными потоками | Современный асинхронный `aiogram 3.x` с FSM и чистой архитектурой роутеров |
| **Работа с базой данных** | Синхронный `sqlite3` с единой глобальной блокировкой (`db_lock`) | Полностью асинхронный `SQLAlchemy 2.0` (`aiosqlite`) с паттерном Repository |

| **Поддерживаемые модели** | Старое поколение (`gemini-1.5-flash`, `gemini-1.5-pro`) | Полная линейка 2.5: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.5-flash-lite`, `gemini-2.0-flash-thinking-exp` |
| **Форматирование ответов** | Ограниченный MarkdownV2 (лимит 4096 знаков, падения по разметке) | **Telegram 10.1+ Rich Messages (`tg-rich-converter`):** нативные таблицы, KaTeX, спойлеры `<think>`, ответы до 32 768 знаков |
| **Быстрые действия в чате** | Отсутствовали | Кнопки под ответом: `[🔄 Еще раз]`, `[↩️ Откатить шаг]`, `[📥 Экспорт диалога]`, `[⏹️ Стоп]` |
| **Песочница Python** | Отсутствовала | **Изолированная песочница `[🐍 В песочницу]`:** расчеты с чистого листа на серверах Google без галлюцинаций |
| **Управление размышлениями** | Отсутствовало | **Thinking Budget:** выбор глубины анализа (⚡ Мгновенно / ⚖️ Баланс / 🔬 Глубокий) |
| **HUD-индикатор квот** | Отсутствовал | **Speed & Token HUD:** прозрачный вывод скорости и токенов (`⚡ 3.3s • 📊 1221 токенов`) |
| **Тайм-аут ZK-сессии** | Фиксированный 1 час | **Настраиваемый TTL:** 15 минут, 1 час, 8 часов, 24 часа в Настройках |
| **Поиск в сети (Grounding)** | Нестабильный, без индикации в интерфейсе | Автоматическое определение Google Search с бейджем в меню выбора |
| **Обработка квот (HTTP 429)** | Бот падает с ошибкой в чат | **Многоуровневый каскад:** авто-переход на `gemini-2.5-flash` с сохранением тулов и сноской внизу |
| **Ввод мастер-пароля и ключа** | Только текстом в чат (секреты видны на экране) | **Telegram Mini App (WebApp)** с маскировкой •••••• + мгновенный автоперехват в чате за 0.25с |
| **Защита от утечки ключей** | Отсутствовала | Regex-перехват случайно отправленных ключей `AIzaSy...` с удалением за 0.25 сек |
| **Управление RAG-памятью** | Только добавление документов в общую кучу | Интерактивное меню: список файлов текущего диалога с кнопками удаления конкретных документов |

## Ключевые возможности

* **Официальный Google GenAI SDK (2025/2026):**
  * Поддержка всех актуальных моделей: gemini-2.5-flash, gemini-2.5-pro, gemini-2.5-flash-lite, gemini-2.0-flash-thinking-exp.
  * Интеграция живого веб-поиска Google Search Grounding с наглядным бейджем в меню.
  * **Многоуровневый Fallback 429:** при превышении квот флагманов запрос мягко перенаправляется на `gemini-2.5-flash` с сохранением тулов поиска и песочницы, а под сообщением выводится прозрачная сноска.
  * **Thinking Budget:** настраиваемая глубина размышлений моделей Gemini 2.5 (0, 1024 или 4096 токенов).
* **Telegram 10.1+ Rich Messages & Высокоскоростной стриминг:**
  * Интеграция библиотеки `tg-rich-converter`: нативные таблицы `<table bordered striped>`, математические формулы KaTeX `<tg-math>`, разворачиваемые спойлеры `<details><summary>` для блока размышлений модели.
  * Лимит длины одного ответа увеличен до **32 768 символов** (вместо устаревших 4096).
  * Скоростной стриминг с шагом 0.8 сек и автоматическим каскадным фоллбэком на чистый текст при ошибках разметки.
  * Пользовательский переключатель форматов (Rich 10.1+ vs Классический MarkdownV2) в Настройках.
* **Интерактивные быстрые действия под каждым ответом:**
  * `[⏹️ Стоп]` во время стриминга — мгновенная остановка генерации для экономии квот токенов.
  * `[🔄 Еще раз]` — удаление предыдущего ответа и повторная генерация на тот же запрос.
  * `[↩️ Откатить шаг]` — удаление пары сообщений (вопрос + ответ) из зашифрованной базы данных.
  * `[📥 Экспорт диалога]` — моментальная выгрузка всей переписки в красиво оформленный файл Markdown `.md`.
* **Выделенная изолированная песочница Python (100% точность):**
  * Запуск расчетов по кнопке `[🐍 В песочницу]` под сообщениями бота.
  * Выполнение с чистого листа (zero dialog history) — модель решает задачу в облачном интерпретаторе Google Cloud без влияния контекста переписки и без галлюцинаций.
  * Сквозное сохранение и вопроса, и проверенного результата в активный диалог.
* **Архитектура Zero-Knowledge (Нулевое разглашение):**
  * Сервер не хранит мастер-ключей и не имеет доступа к переписке и личным API-ключам пользователей.
  * Пароли хэшируются через **bcrypt**. Ключи шифрования выводятся в оперативной памяти через **PBKDF2-HMAC-SHA256 (480 000 итераций)** и шифруются **Fernet**.
  * Поддержка паник-пароля (экстренное стирание всех персональных диалогов) и настраиваемый тайм-аут сессии (15 минут, 1 час, 8 часов, 24 часа).
  * Анти-утечка ключей: регулярные выражения мгновенно перехватывают и удаляют случайно отправленные в чат токены `AIzaSy...`.
* **Token & Speed HUD (Прозрачность BYOK):**
  * Аккуратная строка в шапке ответа: `⚡ 3.3s • 📊 1221 токенов` — пользователь всегда видит время генерации и точный расход токенов своего Google API ключа.
* **Векторная память (RAG / ChromaDB):**
  * Асинхронное векторное хранилище на базе ChromaDB.
  * Загрузка документов (PDF, TXT, MD, DOCX, CSV), семантический поиск релевантных контекстов перед отправкой запроса нейросети.
  * Интерактивное управление: просмотр списка файлов диалога и точечное удаление документов с чанками.
* **Telegram Mini App (WebApp) или Чат-режим:**
  * Всплывающее окно для ввода паролей и API-ключей с маскировкой ••••••.
  * Безопасный ввод в чате с автоматическим удалением сообщений за 0.25 сек.
* **Панель администратора и Подписки:**
  * Управление режимом техработ (Maintenance Mode) и блокировками пользователей.
  * Просмотр детального списка подписчиков и выгрузка отчёта в CSV с корректным русским языком (UTF-8 BOM).

## Архитектура безопасности (Zero-Knowledge)

```text
[Пользователь]
      │
      ├── Вводит мастер-пароль (в WebApp или в чат)
      ▼
[Оперативная память (RAM)]
      │
      ├── Salt из базы данных (16 байт) + Пароль
      ▼
[PBKDF2HMAC-SHA256 (480 000 итераций)] ──> [Временный 32-байтный ключ Fernet]
      │
      ├── Расшифровка личного Gemini API ключа и контекста диалогов
      ▼
[Таймер неактивности (15 мин / 1 ч / 8 ч / 24 ч)] ──> Ключ удаляется из памяти (RAM Purge)
```

> **Важно:** Файл `.env` **не содержит** мастер-ключей шифрования. Даже при полном взломе сервера базы данных данные остаются надёжно защищены стойкой криптографией.

#### Прозрачность векторной памяти (RAG)
Фрагменты загруженных документов хранятся в изолированных коллекциях ChromaDB (`dialog_{dialog_id}`) для работы семантического поиска и точного поиска по ключевым словам. При этом в векторном хранилище нет прямых связей с идентификаторами пользователя, а полная переписка и API-ключи в базе SQLite надежно зашифрованы ключом Fernet.

## Деплой на сервере (Linux / systemd)

Рекомендуемый способ запуска в продакшене — как системная служба с возможностью мгновенного переключения и отката.

### Шаг 1. Размещение на сервере
Склонируйте проект на сервер:
```bash
cd /opt/MyGemini_Zero_v2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

### Шаг 2. Настройка systemd службы
В репозитории подготовлен готовый файл [mygemini-v2.service](mygemini-v2.service):
```bash
sudo cp mygemini-v2.service /etc/systemd/system/mygemini-v2.service
sudo nano /etc/systemd/system/mygemini-v2.service
sudo systemctl daemon-reload
```

### Шаг 3. Переключение на новую версию
Остановите старую службу и запустите v2:
```bash
sudo systemctl stop mygemini && sudo systemctl start mygemini-v2

# Проверка логов
journalctl -u mygemini-v2 -f

# Автозапуск при загрузке
sudo systemctl enable mygemini-v2
```

## Автодеплой WebApp (GitHub Pages)

В проект встроен GitHub Actions workflow (`.github/workflows/deploy-pages.yml`), который **автоматически развертывает страницу WebApp при каждом коммите/пуше**.

1. В репозитории откройте: **Settings** -> **Pages**.
2. В выпадающем меню **Source** выберите **GitHub Actions**.
3. При пуше в `main` страница опубликуется автоматически.
4. Скопируйте ссылку (например, `https://username.github.io/MyGemini_Zero_v2/`) и укажите в `.env`:
   ```ini
   WEBAPP_URL=https://username.github.io/MyGemini_Zero_v2/
   ```
5. Перезапустите бота.
